╔══════════════════════════════════════════════════════════════════════════════╗
║                           SETUP STEPS (10 MINUTES)                           ║
╚══════════════════════════════════════════════════════════════════════════════╝

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: CLONE REPOSITORY                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

git clone https://github.com/Mohnish111004/aquavision.git
cd aquavision

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: BACKEND SETUP                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

cd backend
pip install -r requirements.txt

# Train the model (IMPORTANT - model not in GitHub)
cd model
python3 train_model_simple.py
cd ..

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: FRONTEND SETUP                                                       │
└──────────────────────────────────────────────────────────────────────────────┘

cd ../frontend
npm install

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: RUN APPLICATION                                                      │
└──────────────────────────────────────────────────────────────────────────────┘

TERMINAL 1 (Backend):
  cd backend
  python3 app.py
  
  ✅ Should show: "Server running on http://localhost:5001"

TERMINAL 2 (Frontend):
  cd frontend
  npm run dev
  
  ✅ Should show: "Local: http://localhost:5173/"

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 5: OPEN BROWSER                                                         │
└──────────────────────────────────────────────────────────────────────────────┘

http://localhost:5173

✅ You should see AquaVision AI dashboard!

╔══════════════════════════════════════════════════════════════════════════════╗
║                              TROUBLESHOOTING                                 ║
╚══════════════════════════════════════════════════════════════════════════════╝

❌ "Module not found"
   → Run: pip install -r requirements.txt (backend)
   → Run: npm install (frontend)

❌ "Model file not found"
   → Run: cd backend/model && python3 train_model_simple.py

❌ "Port already in use"
   → Kill process: lsof -ti:5001 | xargs kill -9 (macOS/Linux)
   → Or change port in backend/app.py

❌ "Cannot connect to backend"
   → Check backend is running on port 5001
   → Check terminal for errors

❌ "Dataset not found"
   → Dataset too large for GitHub
   → Contact repository owner or use your own data

╔══════════════════════════════════════════════════════════════════════════════╗
║                      ONE-LINER SETUP                                         ║
╚══════════════════════════════════════════════════════════════════════════════╝

# Clone and setup everything
git clone https://github.com/Mohnish111004/aquavision.git && \
cd aquavision && \
cd backend && pip install -r requirements.txt && \
cd model && python3 train_model_simple.py && cd ../.. && \
cd frontend && npm install && cd ..

# Then run in 2 terminals:
# Terminal 1: cd backend && python3 app.py
# Terminal 2: cd frontend && npm run dev

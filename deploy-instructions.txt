🚀 QUICK DEPLOYMENT (10 minutes)

Since Flask doesn't work well on Vercel's free tier, use this approach:

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Deploy Backend to Render.com (Free)                                 │
└──────────────────────────────────────────────────────────────────────────────┘

1. Go to: https://render.com
2. Sign up with GitHub
3. Click "New +" → "Web Service"
4. Select repository: Mohnish111004/aquavision
5. Configure:
   
   Name: aquavision-backend
   Root Directory: backend
   Build Command: pip install -r requirements.txt
   Start Command: gunicorn app:app

6. Add Environment Variables:
   
   DATABASE_URL=sqlite:///aquavision.db
   SECRET_KEY=change-this-secret-key
   JWT_SECRET_KEY=change-this-jwt-secret

7. Click "Create Web Service"
8. Wait 3-5 minutes
9. Copy your URL: https://aquavision-backend-xxxx.onrender.com

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: Deploy Frontend to Vercel                                           │
└──────────────────────────────────────────────────────────────────────────────┘

1. Go to: https://vercel.com/new
2. Import repository: Mohnish111004/aquavision
3. Configure:
   
   Framework: Vite
   Root Directory: frontend
   Build Command: npm run build
   Output Directory: dist

4. Add Environment Variable:
   
   VITE_API_URL=https://aquavision-backend-xxxx.onrender.com
   (Use your Render URL from Step 1)

5. Click "Deploy"
6. Wait 2-3 minutes
7. Your app is live! 🎉

┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

Problem: Backend not responding
→ Check Render logs in dashboard
→ Verify environment variables are set

Problem: CORS errors
→ Update backend/app.py CORS origins
→ Include your Vercel URL
→ Push to GitHub (auto-deploys)

Problem: API calls failing
→ Check VITE_API_URL in Vercel
→ Test backend URL directly in browser
